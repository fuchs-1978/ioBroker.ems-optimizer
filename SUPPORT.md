# Support and issue reporting

Use the [repository issue tracker](https://github.com/fuchs-1978/ioBroker.ems-optimizer/issues) for bugs and feature requests. The maintainer's public GitHub identity is [fuchs-1978](https://github.com/fuchs-1978).

Include the adapter version, relevant event times with timezone, affected vehicle/device, expected and actual behavior, and a small relevant diagnostic excerpt. Device commands, acknowledgements and electrical response are separate evidence. Do not publish passwords, tokens or unrestricted diagnostic archives. Avoid repeated large SQL/history exports; reuse the existing bounded diagnostics and issue evidence first.

No public support email address has been specified. A generated GitHub no-reply commit identity is not a receiving support mailbox; no email is inferred or invented here. Contact-email checker findings remain open pending the maintainer's explicit public address. Repository topics are repository settings, separate from package/code changes.

Passing software tests, a GitHub release and installation on a plant are separate facts. npm publication and ioBroker Latest admission remain explicitly deferred.
