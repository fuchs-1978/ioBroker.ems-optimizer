# Alpha 298 – Gemeinsame Startplanung für Haushaltsgeräte

Alle für den Fernstart freigegebenen und betriebsbereiten Geräte der Programmtabelle nutzen denselben Netzfahrplan und dieselben Strompreise. Jedes weitere Gerät rechnet die Viertelstundenprofile aller bereits eingeplanten Geräte zum erwarteten Netzbezug hinzu. Das EMS berücksichtigt den zeitlichen Verlauf auch bei einem tatsächlichen Start zwischen zwei Viertelstunden.

Bereits laufende Programme und versendete Startaufträge belegen zuerst ihre voraussichtlichen Restleistungen. Danach folgen startfähige Automatikgeräte in der Reihenfolge ihrer Fernstartfreigaben. Bei gleicher Freigabezeit entscheidet die Reihenfolge im Admin. Wartende Geräte im Modus **Beobachten** erhalten anschließend eine gemeinsame Vorschau. Läuft ein beobachtetes Gerät tatsächlich, zählt sein Verbrauch bei den Automatikgeräten mit. Für ein laufendes Gerät ohne verwertbares Restprofil wartet die Planung auf eine eindeutige Rückmeldung, etwa das Programmende.

Zwei Programme können parallel laufen, wenn genügend Überschuss vorhanden ist oder die gemeinsamen Stromkosten dafür sprechen. Beispielsweise kann ein zweites Gerät starten, sobald das erste vom Aufheizen in eine verbrauchsarme Programmphase wechselt. Die Planung sucht für jedes Gerät den günstigsten Start innerhalb seiner eigenen Fertig-bis-Frist. Das Datum zur eingetragenen Fertig-bis-Uhrzeit bleibt für dieselbe Fernstartfreigabe erhalten.

Alle 15 Sekunden liest das EMS die aktuellen Freigaben, Programmzustände, Netz- und Preisprognosen. Es baut die Reservierungen für wartende Geräte neu auf. Geänderte Prognosen können den Start vorziehen oder verschieben. Bei entzogener Freigabe wird das Zeitfenster frei. Ein gesendeter Start bleibt während ausstehender Rückmeldung über einen Adapterneustart hinweg berücksichtigt, höchstens bis zum erwarteten Ende. Meldet das Gerät den tatsächlichen Start, folgt das Restprofil diesem Zeitpunkt. Eine bestätigte Beendigung gibt die Restleistung frei.

Unmittelbar vor jedem Startauftrag prüft das EMS nochmals die Gerätefreigaben, Betriebszustände und Programmauswahlen, die Schreibfreigabe, die Fertig-bis-Frist sowie Gültigkeit, Stand und Inhalt der verwendeten Netz- und Preisprognosen. Ändert sich während der Prüfung eine dieser Voraussetzungen, entfällt der Auftrag für diesen Zyklus. Die Freigabe kann im nächsten Zyklus neu bewertet werden. Für einen bereits versendeten Startauftrag bleibt die Einmal-Auslösung je Freigabe erhalten.

In `Devices.Programs.N` zeigt `plan.plannedStartAt` den aktuellen Start und `plan.forecastUpdatedAt` den verwendeten Fahrplanstand. `reservation` enthält das erwartete Lastprofil nach Startauftrag oder Laufmeldung. `waitingForRunningProfile` nennt laufende Geräte mit unbekanntem Restprofil. Der Ansagetext wird bei einer geänderten Planung aktualisiert. Die Ansage-ID bleibt je Freigabe und Programmauswahl stabil.
