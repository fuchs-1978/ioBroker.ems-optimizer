# Alpha.207 – Gemeinsamen Warmwasserbedarf im Nachtblock verteilen

Der Fahrplan berücksichtigt beim gleichmäßigen Aufheizen neben der Wärme bis zur nächsten PV-Versorgung auch die erforderliche Reserve für den teureren Preisblock. Ein kleiner rechnerischer Fehlbetrag im ersten Viertelstundenintervall kann in der gleichmäßigen Leistung enthalten sein, wenn diese die Mindestreserve rechtzeitig deckt. Ein kalter Speicheroberbereich und eine bereits unterschrittene Mindestreserve behalten den unmittelbaren Bedarfspfad.

Im eingefrorenen Wärmemodell für 07.11. 23:00 bis 08.11. 05:00 sank die höchste geplante Netzleistung von 9,746 auf 3,784 kW. Die eingeplante Netzheizenergie von 17,011 kWh und die modellierte Reserve von 10,967 kWh am Preisanstieg blieben gleich. Der Vergleich verwendet identische Entnahme, Verluste und Preise. Die produktive Ausgangsfreigabe wird weiterhin separat geprüft.
