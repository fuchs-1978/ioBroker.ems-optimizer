# 0.17.0-alpha.169 — guarded continuation without a follow-up current ACK

On 29 October the Mii stopped after an established 8 A session received an 11 A follow-up command without a matching ACK within the existing timeout. The timeout latched the output fault before the established-session telemetry bridge could apply. This identifies the software stop path, not the physical cause of the missing go-e response.

The output now captures a private witness when dispatching an ordinary current change from an owned, established, freshly observed session. After the ACK deadline, that exact pending command may remain held without any actuator writes if the existing telemetry bridge independently proves continued safety. It reserves at least the greater of the previous confirmed current and the possibly applied sent current, together with retained power, peer/heater and coordinated reservations. Fresh SMA import/export and phase measurements, house fuse, device/commissioning limits, active operator caps, ownership, releases and SoC gates remain mandatory. Small household import alone is not a protection violation.

An unacknowledged command is not marked acknowledged. The original send time, pending command and source timestamps are preserved. ResponseState remains command_ack, with zero deadline remaining and an explicit ACK warning. There is no further current increase, decrease or phase change during this hold. A real late ACK may reconcile that exact command only after the same independent safety checks; its actual source time is retained and electrical response is assessed separately. It is not converted into an on-time ACK or proof of charging uptake.

Starts, phase changes, missing witnesses, changed identity/topology/priority, explicit OFF/fault/conflicting feedback, bad quality, withdrawn releases, unknown/stale independent safety data and insufficient worst-case headroom do not gain this exception. Existing stop/fault behavior remains for those conditions. The guard is intentionally conservative and can stop when safety cannot be proven even without a measured overload. An already latched fault is not remotely reset by this change; installing/restarting follows the existing startup reconciliation.

Tests cover 1P/3P continuation, long device telemetry gaps without fabricated timestamps, conservative command reservations, delayed ACK source time, invalid feedback, fresh independent protection failures, device caps, withdrawn release, absent witness and phase/start exclusions. Full automated checks and CI are reported separately from installation and natural plant acceptance. No real actuator test, SQL/history query or additional raw recording is introduced.
